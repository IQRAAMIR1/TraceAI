# TraceAI
**AI-Powered Recovery for Missing Persons**

### Problem
In Pakistan, there is no real-time system to connect missing-person reports with community sightings. Critical leads get lost in manual checking and social media, delaying rescue efforts.

### Solution  
TraceAI is a community platform that uses Gemini AI to instantly match missing-person reports with public sightings by comparing descriptions, locations, and photos.

### How It Works
1. **Report**: Family submits missing person details + photo
2. **Sighting**: Public submits a sighting with location + photo  
3. **AI Match**: Gemini AI auto-compares and flags potential matches
4. **Alert**: Families and authorities get notified instantly
5. **Map**: Hotspot Map visualizes cases and sightings

### Key Features
- Report & Browse Missing Persons
- Submit Sightings with Photo Upload
- AI-Powered Face + Text Matching
- Real-time Notifications & Alerts
- Hotspot Map for Case Clusters
- Secure & Confidential Data

### Tech Stack
`React + Vite` · `Supabase` · `Gemini AI` · `OpenStreetMap/Leaflet` · `Vercel`

### Impact
TraceAI turns every citizen into a first responder, reducing the time between a person going missing and them being found.
